# undertale-3ds

An unofficial runtime that lets you play your own copy of UNDERTALE on a Nintendo 3DS (New 3DS, Old 3DS and Old 2DS).

**Status: work in progress, not released yet.**

**Trailer:** coming soon.

## Bring your own game

This project contains no game files, art, music, text or game code. You build the 3DS version yourself from a copy of
UNDERTALE you bought on **Steam** or **GOG**; the builder checks for an official, purchased copy. Please buy the game:
https://store.steampowered.com/app/391540/Undertale/ or https://www.gog.com/game/undertale
