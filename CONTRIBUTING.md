# Contributing to undertale-3ds

Thanks for your interest. The project is not released yet, so the code isn't here yet either.

Ground rules that will stay the same:

- **No game content, ever.** Don't add UNDERTALE files, art, music, text, or code taken or decompiled from the game,
  in commits, issues or pull requests. The project only works with a copy each person bought themselves.
- **Purchased copies only.** Help is only available for official copies from Steam or GOG. Questions about other copies
  will be closed.
- **AI-assisted development.** Much of this project's code is written with the help of AI tools. Contributions are
  welcome either way; please mention it if you used AI tools.
- **No money.** The project takes no donations and nothing about it is sold.

Bug reports: please use the issue template and say which console you used (New 3DS, Old 3DS or Old 2DS).
